# UPDATE 1.0.0 | 04/10/2026

## New

- First release of lsx_lib, the shared library behind LSX Assets scripts.
- Script Studio and every lsx_lib UI in the LSX look: green-black surfaces, Chakra Petch headings, IBM Plex Sans text, square corners and the X gradient.
- Everything is named `lsx_*`: the resource, its events, exports, convars and database tables, `/lsx_config`, the `lsxtest` console command and the `__lsx_cb_` callbacks.
